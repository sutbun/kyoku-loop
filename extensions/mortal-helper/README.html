KyokuLoop Mortal Helper — DEV-11.05-6

選んだ牌譜を1件ずつMortalで解析し、JSON保存・KyokuLoopへの登録が完了してから次へ進みます。初版20の1件保存は本人確認済みです。通常ブラウザの一括登録も本人確認済みです。本版は自動選択・進捗表示を簡素化しています。新しい画面の実操作は通常利用時に確認してください。

すでにHelperを使っている場合

AI側で同じフォルダーの中身を更新します。Chromeなら chrome://extensions、Braveなら brave://extensions を開き、既存の「KyokuLoop Mortal Helper」の再読み込みボタン（丸い矢印）を1回押してください。追加されたローカルサイト権限の確認が出た場合は内容を確認します。拡張を開いて DEV-11.05-6 と出れば更新完了です。

拡張を削除して入れ直す必要はありません。読み込んだフォルダーの場所は初版と同じままです。別フォルダーから2つ目を追加すると二重送信防止の記録を共有できないので、同じ拡張を更新します。

まとめて解析・登録する

  1. KyokuLoopを起動し、普段のブラウザで PCのKyokuLoop を1つ開いたままにします。牌譜URLは先にKyokuLoopへ追加しておきます。
  2. ツールバーの拡張を開きます。処理できる未登録の四人半荘を、古い順に最大20件まで自動で選びます。個別に変更するときだけ「対象を変更」を開きます。ルール未確認の牌譜は四人半荘か確認して手動で選びます。モデルの初期値は4.1bで、右上の「⋯」から変更できます。選んだモデルは記憶されます。
  3. 「○件を解析・登録」を押します。開いたMortalタブとKyokuLoopタブを残してください。拡張の小窓は閉じても処理が続きます。ページの送信ボタンを重ねて押す必要はありません。
  4. 進捗に登録完了の件数と総数、現在の処理・待機秒数が表示されます。「○件を登録しました」で完了です。「KyokuLoopを開く」で元の対局へ戻れます。登録済みの牌譜は拡張の一覧から自動で消えます。JSONも既定のダウンロード先の KyokuLoop-Mortal に保存されます。

最大20件を選べます。登録完了ごとに30秒空けます。ブラウザが保存先を毎回尋ねる設定の場合は確認が表示されます。

止まったときの情報をコピーする

停止メッセージの下の「エラー情報をコピー」を1回押すと、進捗・内部エラーコード・牌譜ID・結果ID・保存先・JSON保持状態がまとまります。そのままチャットへ貼り付けてください。コピーが拒否された場合は文字欄が選択されるのでCtrl+Cを押します。JSON本体やCookie、学習履歴、本人確認情報は含みません。

本人確認待ち

入力フォーム内の本人確認欄が表示され送信できないときは「本人確認待ち」で待機します。チェック操作が必要なら本人が行ってください。確認が終わり送信ボタンが有効になると、そのまま自動で続きます。本人確認の操作や応答の読取、アクセス制限の回避は行いません。

止める・再開する

「この1件で止める」は送信前ならすぐ一時停止し、送信済みならその1件を保存・登録してから次へ進むのを止めます。サイトで受け付け済みの解析を取り消す操作ではありません。

ローカル登録だけが失敗した場合はJSONを拡張内に保持します。KyokuLoopを開き直して「登録を再開」を押すと、そのJSONの登録だけを再試行します。ブラウザや拡張の再起動後も自動で再送しません。

本人確認・アクセス制限・内容の不一致・送信状況不明では止まります。表示された文言を伝えてください。同じ対局を何度も解析依頼しないでください。JSONの受け渡しが途切れた場合も、保存済みJSONをKyokuLoopで登録できます。

未登録JSONを保持していない一時停止中は右上「⋯」の「この一覧を終了」で未送信の一覧を解放できます。過去の送信・結果の記録は消しません。

開いているMortalページ1件だけの保存と、処理履歴・対応表の保存は右上の「⋯」にあります。

保存する情報と権限

Mortalの公開ページと、PC内の 127.0.0.1:1460 のKyokuLoopページを操作します。元URL・モデル・結果ID・進捗は拡張ローカルに最大1000件、登録待ちJSONは1件だけ保持します。他端末や外部サービスへ同期せず、Gitにも送りません。Cookie・本人確認トークン・サイト内部のJavaScript状態を読み出しません。

既存のKyokuLoop登録APIで内容を検証します。問題・回答・学習履歴・未保存入力は上書きしません。ブラウザ全体の設定、認証回避、OS常駐、新しい公開APIは追加しません。

新しいPCで初めて追加する場合

Braveの brave://extensions でデベロッパーモードをオンにし、「パッケージ化されていない拡張機能を読み込む」から次のフォルダーを選びます。ZIPではなくフォルダーを選びます。

{{EXTENSION_DIRECTORY}}

Edge / Chromeでは edge://extensions / chrome://extensions から同様に追加します。読み込んだフォルダーは移動・削除しません。
