KyokuLoop Mortal Helper — DEV-11.04-20

通常ブラウザで開いたMortalの1件について、開始操作から送信・解析完了待ち・JSON保存まで進める検証用拡張です。実サイトでの動作確認はまだです。

初回だけ行うこと（WindowsのBrave）

  1. Braveのアドレス欄に brave://extensions を入力して開きます。
  2. 「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」を押します。
  3. 次のフォルダーを選びます。ZIPファイルではなく、このフォルダーを選びます。

    {{EXTENSION_DIRECTORY}}

  4. 「KyokuLoop Mortal Helper」が表示されたら追加完了です。ツールバーの拡張機能メニューからピン留めすると、次から開きやすくなります。

Edge / Chromeでは、それぞれ edge://extensions / chrome://extensions から同じ方法で追加します。拡張用フォルダーは移動・削除しないでください。

まず1件だけ確認

  1. KyokuLoopで未解析の四人半荘の「Mortalへ」を押します。すでに依頼済みの対局は使いません。
  2. Mortalの入力ページを一度読み直します。牌譜URL・対象プレイヤー・AIがMortal・UIがKillerduckyであることを確認します。設定を拡張が勝手に変更することはありません。
  3. ツールバーの「KyokuLoop Mortal Helper」を開き、表示された元URLとモデルを確認して「この1件を開始」を押します。ページ側の「送信」を重ねて押す必要はありません。
  4. 結果画面へ移動したら、もう一度拡張を開きます。「ファイルを保存しました（内容検証・アプリ登録は未実施）」となり、既定のダウンロード先の KyokuLoop-Mortal に結果IDのJSONがあれば、この範囲の成功です。ブラウザの設定によっては保存確認が表示されます。

保存済みJSONは、従来どおりKyokuLoopで選んで登録できます。初版はファイル保存までです。この専用フォルダーからの自動登録や、URL一覧の連続処理は追加していません。

停止した場合

拡張に表示された文言だけを伝えてください。同じ対局を何度も送信しないでください。本人確認・アクセス制限・フォーム変更・別ページへの移動・時間切れ・保存失敗で停止し、自動再送しません。停止ボタンはサイトで受け付け済みの解析を取り消すものではありません。

「送信操作を開始・結果は未確認です」から止まった場合、実際に依頼が届いたか不明なことがあります。拡張は同じ設定を再送しません。元URLと結果IDは「最近の処理・元URLとの対応」で確認できます。「対応表を保存」は解析JSONとは別のtxtファイルを作ります。

保存する情報と権限

対象は mjai.ekyu.moe の入力・進捗・Killerducky結果ページです。拡張のローカル記録には元URL、選択したモデルと対象、結果ID、保存状態を残します（最大1000件）。他端末へ同期せず、Gitにも送りません。Cookie・本人確認トークン・サイト内部のJavaScript状態を読み出しません。

ページ操作、拡張ローカル保存、ページ遷移の追跡、ダウンロード、待機時間の管理を使用します。ブラウザ全体の設定は変更せず、既存ダウンロードを削除・上書きしません。ブラウザや拡張の再起動後に送信を自動再開しません。
