# 保存牌譜と件数

11.05-12から、Windows/iPad共通の「牌譜」タブの「保存牌譜」で「すべて ○件」「未解析 ○件」「解析済み ○件」を表示し、押した状態に一覧を絞り込む。初期表示は「すべて」。URL/解析結果の追加入口の下、全選択・削除操作の上へ配置する。既存のフィルターボタンの文字サイズ・配色を使い、幅が足りない場合はボタン単位で次の行へ折り返す。

- 件数は一覧から削除されていない保存対局を対象とし、10件の初期表示より先の分も含む。
- 結果が1件以上登録された対局を「解析済み」とする。同じ対局に複数モデルの結果があっても1件。検証済みで復習対象問題がない対局も含む。
- 結果が未登録の対局は「未解析」。本人申告の依頼中も含む。外部サイトだけで解析済みかどうかを推測しない。
- フィルター切替時に表示件数を10件へ戻し、選択を解除する。全選択は現在のフィルターに合う全件（次ページを含む）に適用する。
- 該当0件でも件数ボタンを表示する。登録・削除・既存のホーム更新に合わせて件数と表示行を更新する。入力中のURLを消さない。

11.05-11から、状態フィルターの下に「並び順」を表示し、「追加順」（初期値）と「対局日時」を選べる。どちらも新しい順で、対局日時がない牌譜は日時順の末尾に表示する。同じ対局日時は追加日時で、追加日時も同じ場合は元の登録配列の後方を先に表示する。並び替えで先頭10件へ戻し、現在のフィルターと選択済み牌譜は保持する。全選択は引き続き未表示分を含む。選んだ順序は画面内で保持し、起動時は追加順に戻る。スマホ・iPadの保存牌譜にも同じ並び替えを適用する。

JSON登録・元対局への紐付け・問題・回答・学習履歴の保存形式は変更しない。並び替えは表示だけを変え、保存された登録順を書き換えない。
