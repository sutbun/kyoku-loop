# 一局レビュー

「牌譜」の各解析結果から「一局レビュー」を開き、局/本場を選ぶ。選択した一局の全手順を端末へ保存し、以後はオフラインでも確認できる。端末で登録したMortal原本からも局データを生成できる。新しい解析依頼は行わない。

盤面と手牌を主役にし、実打を重複する常設右パネルは置かない。手牌上に最大3候補と元の推奨度を表示する。上位3つだけで100%に再計算しない。赤牌はMortalの別候補として扱う。不一致は実打の推奨度が最大候補より小さい判断とし、同率最大は含めない。鳴き/リーチ等の未対応評価はクイズ化せず、牌譜として確認できる。

クイズなしは評価を表示する。クイズありは自分の評価済み打牌判断で止まり、手牌をタップした時点でその牌を回答として保存し、AI候補・実打・回答を表示する。答え合わせボタンの操作は不要。タップだけでは次の手順へ進めず、回答をその場で確認できる。未回答のまま次へは進めない。通常の前後移動は全員のツモ/打牌/副露等を一手ずつ進め、回答後の「次の判断へ」は自分の次の判断へ移る。異なる牌を回答しても元の牌譜を再生する。

盤面の余白をタップで次へ。ホイール下/上、スワイプ上/下で前/後へ進む。慣性で複数手進められ、クイズ未回答判断で止まる。手牌・牌・ボタン・メモ・一覧は余白操作から除外し、スワイプ後のクリックで二重に進めない。盤面下の操作説明文は表示しない。

同じ半荘の収録順に局をつなぐ。局末で次へ進めると次局の冒頭、局頭で前へ戻すと前局の最後を開く。最初と最後の局の外へは循環しない。局をまたぐ際は慣性の残りを止め、読み込み中の重複移動を防ぐ。回答後の「次の判断へ」も次局へつなぎ、次局に評価済み判断がなければ冒頭を開く。同じ半荘内では局選択欄や保存場面から切り替えた場合もクイズあり/なしを引き継ぐ。回答/選択は局ごとに保持し、通常送りで局を越えるときは冒頭/末尾、局選択欄ではその局の途中位置を開く。未取得の局をオフラインで開けない場合は現在の局と記録を保ち、接続後に同じ移動を再試行できる。

前/次のAI不一致ボタンはその一局内だけを移動し、端では無効にする。途中位置/モード/選択/回答は通常の5問復習と別に保持する。保存は一押しでブックマークし、必要時だけタグとメモを開く。初期タグは手作り/押し引き/鳴き・リーチ、1場面1タグ、タグなし可。タグ管理は既存タグの名前変更と統合を用意し、保存操作でタグ数を増やさない。同じ対局/席/局/手順の保存を重複させない。学習の「保存した場面」からタグで絞り込み、前後の文脈を含めて開ける。場面保存だけでは通常の復習に登録しない。

レビュー記録は使用端末に保持する。端末間の通常SRS同期と混ぜない。Windowsは既存SQLiteバックアップ、iPad/iPhoneは既存の端末記録ファイルに含めて保全する。古いバックアップも読めるようにし、新しい局面保存/回答を古いバックアップで上書きしない。
