# iPadだけで登録・復習する

11.03-4から、初回の準備を済ませた端末では、取得済みMortal JSONの登録・問題作成・復習・履歴・期限計算にWindowsの起動は不要。Mortalの解析とJSON保存は従来の公式サイトと[保存手順](IPAD-MORTAL-JSON-SAVE.md)を使う。

## 最初の1回

1. Windows版を起動し、iPadを従来の本人用HTTPS接続へつなぐ。ホーム画面のKyokuLoopで11.03-4を確認する。
2. ホームの「端末だけで使う準備」を押し、「端末内の取り込み準備完了」を確認する。検証用の実行基盤約14MBを同じ接続先から保存する。
3. 以後はWindowsとTailscaleを止めても、ホーム→「牌譜を追加」→「解析結果を追加」でJSON / JSON.gzを選べる。局数・Mortalモデル・解析対象席を確認し、「この端末に登録」を押す。

元牌譜の指定は任意。端末に保存した雀魂URLを選べば、Windowsに戻ったときも同じ解析待ち対局へ紐付く。日時や名前だけで対局を推測しない。

「今すぐ学ぶ」で当日から練習できる。定期復習の初回期限は登録日の翌日。同じ対局・席の自動問題は最大3問で、同じJSONの再登録で問題や回答を増やさない。対象形式・除外する判断は[Mortal取り込み仕様](MORTAL-IMPORT.md)と共通。

11.04-10から、牌譜屋から取得した雀魂URLも端末内へまとめて保存できる。[一括コピー・txt保存・追加の手順](IPAD-BULK-IMPORT.md)を参照。

## 同期と保管

- 接続が戻ったら、解析待ちURL→未同期の結果→回答の順にWindowsへ送る。「今すぐ同期」も使える。Windows停止中は端末内に保持し、別のWindows保存先へ切り替えない。
- 11.03-8から、端末内登録の準備を先に済ませた場合も、「問題を端末に保存」または「今すぐ同期」でWindowsの問題を初回取得できる。0問でも手動同期でき、保存中の取得失敗はその場で表示する。既存の端末内JSON・未送信回答・途中の復習は引き続き保護する。
- 結果はWindowsでも再検証する。登録が成立した直後の通信切断でも再送で二重登録しない。登録日を引き継ぎ、後日の同期で初回期限を遅らせない。既存問題の期限・回答は上書きしない。
- 「端末の管理」→「記録をファイルに保存」は、元JSON・問題・回答・途中の復習を含む。未同期の間は特にこのファイルも保管する。端末保存領域やサイトデータを消すとローカルの記録も消える。
- 復旧は、準備済みの記録がない端末で「記録ファイルから復旧」。元JSONを再検証してから一括保存する。既存の回答・途中の復習・ローカル登録がある端末への上書きは拒否する。schema2のファイルはiPad側へ復旧して同期する。旧schema1も対応する。
- ファイル上限は20MB。端末記録全体も20MB以内。容量不足・検証不一致・保存失敗では現在のデータを保持する。

## 実装と確認範囲

IndexedDBの既存DB/storeを維持し、端末内登録を有効にした端末だけ保存形式schema2へ更新する。旧版が新状態を読み書きすることは拒否する。Windows SQLite形式は変更しない。

固定版Pyodide314.0.7 / CPython3.14.2を専用Workerで動かし、Windowsと共通のPython検証器・ID・重要局面選択を使用する。外部CDN・wheel・AIモデルを取得しない。5つの実行基盤ファイルはサイズとSHA-256を検査してCache Storageへ、私的JSONと履歴はIndexedDBへ保存する。ライセンスとソース入手先は端末の管理から開ける同梱NOTICEに記載。

Edgeの通信切断テストと実iPad受入は分けて記録する。Wasm対応の技術資料は[調査記録](IPAD-RUNTIME-RESEARCH.md)。実機での速度・アプリ終了・本体再起動後の保持は本人確認の対象。
