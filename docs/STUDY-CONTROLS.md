# 復習の操作と表示

- 他端末の操作で現在の問題のrevision/cycle/出題状態が変わった場合、既存の状態照合を維持し、復習画面が自動で次の問題へ進む。問題を回答済みにするイベントは追加しない。連続して更新済みでも順に通過し、すべて更新済みならその旨を表示する。未送信の回答や元の復習期限は変更しない。保存の失敗時は無限リトライせず、状態確認から再試行できる。
- 学習の設定で、回答ボタン・選択した時点・選択中の牌をもう一度タップ、の3方式を選べる。初期値は回答ボタン。端末（ブラウザ）ごとに保存し、学習データの同期対象にはしない。iPadはホームの「端末の管理」内、Windowsは学習ライブラリに置く。選び直しと自己評価は維持し、牌の確定だけで理解回数を増やさない。
- 横長画面では回答欄は右側のまま下寄せし、手牌を含む盤面欄の下端へ揃える。選択中の確定操作も欄の下へ寄せる。縦画面は手牌の直下。収まらなければ重ねずスクロールを許す。回答前後で卓を動かさないため、比較欄の高さをあらかじめ確保する。
- 同期の問題は上部バーの固定枠に「同期を確認」と表示する。押すと詳細・再試行を重なり表示する。本文の警告帯を追加しない。オフライン/未送信等の状態も従来どおり上部枠で確認できる。
- 比較欄は「今回」「対局時」「Mortal4.1b」のようなエンジン＋モデル名とする。見出し・牌・推奨度を各列で整列し、推奨度は牌の下へ同じ高さで表示する。評価の計算や問題選定は変更しない。

検証は生成データと隔離されたブラウザ/DBで実施し、実端末UX合格と区別する。playwright.study-controls.config.tsは稼働中サーバーへ要求を送らず、ビルド済みファイルと生成packだけで操作/配置を確認する。
