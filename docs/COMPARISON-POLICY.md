# 回答比較欄のAI推奨度

回答確定後、「今回の回答」「対局時の打牌」「AI推奨」の各牌の右横へ推奨度を小数1桁の%で表示する。狭い画面では同じ列内で折り返す。

Mortalは元結果の37牌区分（通常34種＋赤3種）の選択傾向を使用し、赤牌と通常牌を合算しない。NAGAは従来の34牌種の正規化した重みを使用する。勝率や損失点数を意味しない。問題選定・正解判定は変更しない。

Windowsと新しく同期した端末は保存済み評価から表示値を投影する。旧端末内登録は保持した元JSONを共有検証器で再計算し、元の問題と一致した場合だけ表示へ補完する。元JSONや実行環境がない旧端末データは「—」とし、合算値から赤牌の値を捏造しない。Windowsに同期すると正確な値を取得できる。

回答前の出題Sceneには推奨度を含めない。DBの元Scene・問題ID・復習期限・回答履歴を更新する移行は行わない。旧端末バックアップの追加表示情報なしも受け入れる。

検証: tests/comparison-policy.spec.ts（生成Mortalデータの37種区別、未確定非表示、旧pack受入、不正pack拒否、幅320/390/768での配置と選び直し）。playwright.policy.config.tsはビルド済み資産を全リクエストに対してローカルで応答し、実行中サーバー・実データに接続しない。実行は npm run build の後 npx playwright test -c playwright.policy.config.ts --workers=1。
