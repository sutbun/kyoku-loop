# 端末の出題と回答回数

自主練習は回答回数の少ない問題を優先する。端末に保存した問題の集計値だけでなく、保存済みの回答履歴を使い、古い保存形式で集計値が未保存または履歴より小さくても回答済みを未回答として再選択しない。端末に残る未送信回答は、受信済み履歴に同じイベントIDがなければ加算する。同じ回答を二重には数えない。

この変更は選定に使う回数の読み取りを補うもので、回答履歴・復習期限・理解回数・同期形式・中断した学習は変更しない。通常の復習は引き続き期限が来た問題を対象とし、復習中、手動登録の未学習、自動登録の未学習の順に最大5問を選ぶ。中断した学習は保存した問題列の続きから再開する。

`playwright.repetition.config.ts` は本人の稼働アプリへアクセスせず、生成した207問・古い保存形式・生成画面の回答操作と既存の同期/取消/中断の回帰を検証する。
