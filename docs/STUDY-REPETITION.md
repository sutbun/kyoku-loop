# 問題が多いときの出題順

自主練習は未回答を先に選び、回答済みの問題は最後に回答した時刻が古い順に回す。同時刻なら回答回数、復習中/手動/自動、期限、IDの順に比較する。過去の回答回数が少ない5問だけを何度も続けて出さない。

通常の復習は、期限が来た問題を期限の古い順で最大5問選ぶ。同じ期限なら復習中、手動登録の未学習、自動登録の未学習の順に優先する。新しい期限の復習中問題が、もっと古い期限の未学習問題を追い越し続けない。

端末側は保存済みの回答履歴も使い、古い保存形式で集計値が未保存または履歴より小さくても回答済みを未回答として再選択しない。端末に残る未送信回答は、受信済み履歴に同じイベントIDがなければ加算する。同じ回答を二重には数えない。日時はUTCに換算して比較する。

問題と回答の保存形式、復習期限・理解回数の計算は変更しない。期限が未来の問題は通常復習へ繰り上げない。保留・習得済みを出題せず、同日の定期復習は1回として計上する。中断した学習は保存した問題列の続きから再開する。選定ルールを変えるために進行中の問題列を破棄しない。

`playwright.repetition.config.ts` は本人の稼働アプリへアクセスせず、生成した207問・古い保存形式・生成画面の回答操作と既存の同期/取消/中断の回帰を検証する。
