# 基準NAGAタイプの初期選択

DEV-11.02-2 / 日常版11.02-2。2026-11-02 JST、本人の「1 初期値はニシキ」という回答に基づく。元仕様9.4/12.4の基準タイプの優先を、既存の登録画面へ反映する。

- 記憶がない初回は **ニシキ**。その後は、登録が成功した最後のタイプ名を次回の初期選択に使う。
- 番号はレポート内だけのものとして扱い、対応済み番号0/1のタイプ名が一意に一致する場合だけ選択する。同じタイプでも別レポートで番号が変われば、そのレポートの番号へ対応させる。
- 記憶したタイプがない、同名が複数、対応外番号だけに存在する場合は未選択にする。候補が1つでも別のタイプを勝手に選ばない。必要なら本人が選ぶ。
- 対象プレイヤーは毎回本人が選び、「このプレイヤーで登録」で確定する。表示された初期タイプを変更することもできる。
- 読み込み/取消し/失敗では記憶を変えない。登録済みレポートを別タイプで明示登録した場合は、その成功時の選択を記憶する。既存の問題/回答/期限/IDを置換・再評価しない。

設定はWindows正本SQLiteの既存study_settingsにpreferred_naga_typeとして保存する。レポート/問題と同じトランザクション内で保存し、設定保存に失敗した場合も部分登録しない。SQL版3/IDB版1を維持し、新しいDB移行やiPhone向けの設定操作は追加しない。

SQLiteバックアップへ設定を含め、復元先が未設定の場合だけ復元する。復元先の既存選択を上書きしない。設定のない旧バックアップは初期値ニシキとなり、不正な設定値を含むバックアップは拒否する。
