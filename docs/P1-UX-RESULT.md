## 画面構成とデザイン

主画面はホーム / 牌譜・分析 / 学習の3つ。ライブラリは学習内のタブ。取り込みと履歴は補助ダイアログ。

紙色 `#f6f5ef` と卓の緑 `#245e50`、操作の緑 `#205e4c`。OSの日本語フォント、基本14px、余白は主に8/16/24/32px。Windowsは卓と比較を横並び、900px以下は縦積み、600px以下は下部ナビゲーション。回答用の牌は狭い画面で7枚×2段にし、選択後に確定ボタンを押す。選択色だけでなく牌の持ち上げと押下状態を併用。動きは120〜150ms、reduced-motionでは追加しない。外部フォント・画像・旧ツールの素材は使わない。

## データと実装の境界

- `src/demo.ts` は136枚から固定シードで配牌とツモ/打牌を作る新規の架空データ生成器。4局×32手順。自分は絶対席2、自風は局ごとに変わる。
- 各フレームは打牌直前の自分の13枚と、自分の手番だけツモ1枚、既公開の河、ドラ表示牌、点数を持つ。他家手牌・山・将来ドラは描画用フレームに含めない。
- 5重要局面の順位と評価は人工値。NAGAのJSONキーや重みを実証・正規化したものではない。学習用の7追加局面も同じ生成器由来。
- 副露・リーチ・カン・和了/流局の複雑局面は生成していない。「副露なし・リーチなし」の確定した架空状態のみ表示。P0の実牌譜復元テストを代替しない。
- 手動保存は重要局面をライブラリへ登録。取消時は回答履歴がなければ登録を戻し、履歴があれば保持する。正式な削除/履歴管理設計を確定したものではない。
- 出題は保留・習得済みを除く架空問題から最大5件。自主練習で卒業させない。3/7/14/30日・定期復習の優先順位・同期イベントはP3以降。
- 架空UI状態をlocalStorageに保存し再開できる。破損状態は架空初期状態へ戻す。実学習データの移行方式ではない。

## 再現手順

```powershell
Set-Location E:\dev\kyoku-loop
npm run dev
```

[P1試作](http://127.0.0.1:1460/?demo=1) を開きDEV-11.01-1を確認。起動中ならページを開くだけでよい。P2以降はルートURLが実データ用となり、P1当時の表示・架空の保存状態はこの確認用URLに分離する。

1. ホームの「新しい牌譜を確認」→重要局面の「次」「前」→「学習に保存」→「保存を取り消す」。「全手順」で前後へ移動。
2. ホームの「今日の復習を始める」→牌を選ぶ→「回答する」→3者比較→「理解した」等で次問。5問後に一覧。選択/回答/直前評価を取り消せる。
3. 「学習」→「ライブラリ」で4区分を選び「局面と履歴」を開く。保留/再開/再学習は「変更を取り消す」で戻せる。
4. 「中断してホームへ」→「復習を再開する」。ブラウザ再読込でも架空の進行を保持。
