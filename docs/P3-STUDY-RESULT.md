# P3 実データ復習 — DEV-11.01-3

2026-11-01 JST。P2を満たした実判断を対象に、Windows単体の学習フローを実装した。P1の架空データ/履歴を実学習へ移行していない。

## 動作と保存

- ホームから今日の復習、または「今すぐ学ぶ」で自主練習。期限が来た復習中、手動の未学習、自動の未学習の順に最大5問。初回の期限は登録翌日。保留/習得済みは通常キューから外す。進行中はそのセッションを再開し、別モードへ無言で切り替えない。
- 切る牌の選択→確定→今回/対局時/NAGA推奨の3者比較→自己評価→次問。回答確定前の出題APIとライブラリ一覧には実打牌・推奨・重みを含めない。画面のDOMにも表示しない。レビュー/履歴の明示操作では比較を閲覧できる。自分の手牌以外の隠し情報は出題しない。
- 選択、確定前/後、回答結果、キュー位置をSQLiteへ保存。再読み込み後に同じ問題へ戻る。選択取消・回答選び直し・直前評価の取消が可能。別操作で問題の状態が変わった場合は古い回答を適用せず、変更を示してスキップできる。
- NAGAとの一致は34牌種で比較する（赤5と通常5の評価上の区別を捏造しない）。回答の赤牌そのものは保存する。AIと異なる回答でも自己評価を「理解した」と記録できる。保存した元判断・評価モデルは取り込み直しで置換しない。

| 定期復習の結果 | 期限と状態 |
|---|---|
| 理解1/2/3/4回 | 3/7/14/30日後、復習中 |
| 理解5回 | 習得済み、期限なし |
| 再復習 | 0回、翌日 |
| 保留 | 期限停止、履歴と連続回数を保持 |

期限はJSTの暦日。1回の評価処理では日時を一度だけ採り、深夜0時をまたいでも記録日と期限をずらさない。自主練習の理解/再復習は履歴だけを追加し、期限・連続回数を変更しない。自主練習の保留は出題を停止する。同じ日の定期記録を重ねて卒業を進めない。

## イベントと既存データ

P2の元JSON・判断・登録を保持し、移行前のDBをprivate/app/backups/pre-p3-*.sqlite3へ自動複製してから列/テーブルを追加する。既存の期限やライブラリ区分をリセットしない。新しいDB版を古いアプリで無言で書き換えない。

review_eventsは固有ID、判断ID、日時/日付、端末、サイクル、セッション、回答、自己評価、定期加算の有無、適用前後の状態を持つ。アプリは既存イベントを更新/削除しない。取消はundoイベントを追加し、同じイベントの再送は二重適用しない。項目・セッション・イベントを同じトランザクションで保存し、失敗時は巻き戻す。古い状態へ別回答を重ねる場合はrevisionを確認して拒否する。

ライブラリは今日/未学習/復習中/習得済み/保留/すべてで絞り込む。「局面と履歴」で元の評価と時系列イベントを確認し、保留/再開/再学習を操作できる。取消済み回答も履歴に残す。

## バックアップと復元

[SQLite backup API](https://docs.python.org/3/library/sqlite3.html#sqlite3.Connection.backup)で一貫したDB複製を作成し、圧縮してダウンロードできる。選択ファイルはprivateへ置き、DB版、整合性、参照、元JSONハッシュ、NAGAから再投影した局面、履歴の連鎖などを検証する。外部ファイルのSQLを実行してDB構造を作り替えない。

内容確認で牌譜/問題/履歴件数を表示し、適用時に同じハッシュを再確認する。現在のデータを残して不足するレポート・問題・イベントを追加し、バックアップの方が履歴の続きとなる場合だけその状態を採用する。新しいローカル履歴を古いコピーで巻き戻さない。分岐した履歴は未解決のまま上書きせず、理由を示して止める。適用前にもpre-restore複製を保持する。現在の端末IDと進行があれば保ち、空の復元先にはバックアップの進行を引き継ぐ。

対応する持ち出し形式はsqlite3/gzip。ファイル選択は20MB、展開後256MBまで。大きいDBはprivate内の複製自体を作成できるが、圧縮後20MBを超えるダウンロード/ファイル選択は未対応。同一ドライブ内に保存しただけで別媒体への退避を保証したとは扱わない。P2時代のpre-p3複製は移行前の回復用であり、P3の通常ファイル復元はDB版3を対象とする。
