# 共通の画面構成

11.05-12からWindowsもiPad・スマホと共通の画面構成を使用する。起動時は「学習」。下部タブは「学習」「牌譜」「設定」の3つ。

- 学習: 中断中なら再開を先頭に表示。通常は今日の復習、自主練習、問題一覧への入口の順。復習0問では開始ボタンを出さず、自主練習を主操作にする。問題一覧には学習状態の絞り込み・局面と履歴・保留等の既存操作を残す。
- 牌譜: 「URLを追加」を開いて1件または改行区切りで複数件を同じ欄から追加。有効な1件のときだけ「Mortalへ」を表示。「解析結果を追加」でMortal JSONを登録。入力と確認結果はタブを切り替えても保持し、処理中はタブ操作を止める。入力途中は他タブでも版更新を保留する。
- 保存牌譜: 初期値は追加日時の新しい順。「並び順」で「追加順」「対局日時」を選べる。対局日時も新しい順で、日時不明は末尾。同じ対局日時は追加日時で、追加日時も同じ場合は元の登録配列の後方を先に表示する。「すべて」「未解析」「解析済み」の全件数で絞り込み、10件ずつ追加表示。並び替え時は先頭10件に戻し、絞り込み・選択済み牌譜を保持する。行の左側に日時/順位/状態、その直下に対戦相手を常時表示し、右側に主操作を置く。相手名は12px・既存の薄い文字色を維持し、長い名前や狭い画面では折り返す。行の上下余白は6px。「詳細」には保存日時・Windows受信状態を残す。未同期は行にも表示。準備済みの「問題を見る」は紐付くレポートだけの問題一覧を開く。
- 設定: 学習の設定、保存と同期、端末の管理（記録保存/復旧・容量・ライセンス）。同期の異常や未送信は全タブ共通の上部に残し、詳細から保存と同期を開ける。学習画面にもオフライン保存未確認時だけ設定への入口を出す。

縦横とも復習/再開、自主練習、問題一覧の順に一列で配置する。問題の回答中は既存の画面内配置と下部タブ非表示を維持。「中断して学習へ」で戻る。タブ移動は履歴・登録・同期データを書き換えない。

画面幅が380px以下では、牌譜情報の下に詳細と主操作を左右に並べ、日時と相手名の幅を確保する。Windowsも同じ下部タブと学習トップ・URL入力・Mortal JSON登録・牌譜一覧を使う。

検証は次の順で行う。最後のコマンドは日常サーバーへ接続しないEdgeの架空データ画面/ロジック検証。生成画面の観測と実iPadのUX受入を区別する。

```powershell
npm run build
npm run test:core
npx playwright test -c playwright.phone-tabs.config.ts --project=phone --workers=1
```

## Windowsの機能

- 「牌譜」内の各行の「詳細」に結果登録、依頼操作の申告、モデル別の「牌譜を確認」を置く。JSONの対局行へのドロップも維持する。
- 通常のMortal JSON / JSON.gz選択・複数登録・元牌譜候補・登録後の紐付け表示はiPadと同じ画面部品。PCへの登録は既存inspect/commit、端末内登録/同期は従来の経路を使う。解析済みでも対象問題なしの対局を一覧から除かず、「解析済み・問題なし」と表示する。学習可能な行は「学習可」と「問題を見る」。
- 「レポートURL・NAGA」には既存のレポートURL/JSON/席・モデルの確認を残す。「解析結果一覧」は開閉式で全結果を保持し、元URLが一覧から削除された結果や未紐付け結果も開ける。
- Windowsの重要局面・収録手順・手動学習保存は牌譜の詳細画面。「牌譜に戻る」で一覧へ戻る。iPadに全手順レビューを新設した変更ではない。
- 学習の設定、バックアップと復元、Mortal自動取り込みは「設定」。iPad・スマホ用オフライン版へのリンクと解析の手順は「このPCの管理」内。
- タブ切替でも入力下書きとJSON確認状態、学習セッションを保持する。登録処理中はタブ切替を無効化する。通常時のWindows保存正常表示は省き、処理中/失敗は表示する。

共通化は表示部品と操作の配置だけ。SQLite/IndexedDB/同期/バックアップ形式は維持する。相手名は12pxと既存の薄い色、行の上下6pxを維持する。十分な幅では情報左・主操作右、狭い幅では情報を折り返し、主操作を次行右に置く。学習中はタブを隠し、横長は盤面左・回答右、縦長は回答を盤面の下へ置く。
