# iPad・スマホの画面構成

起動時は「学習」。下部タブは「学習」「牌譜」「設定」の3つ。

- 学習: 中断中なら再開を先頭に表示。通常は今日の復習、自主練習、問題一覧への入口の順。復習0問では開始ボタンを出さず、自主練習を主操作にする。問題一覧には学習状態の絞り込み・局面と履歴・保留等の既存操作を残す。
- 牌譜: 「URLを追加」を開いて1件または一括追加。「解析結果を追加」でMortal JSONを登録。入力と確認結果はタブを切り替えても保持し、処理中はタブ操作を止める。入力途中は他タブでも版更新を保留する。
- 保存牌譜: 対局日時（なければ保存日時）の新しい順。「すべて」「未解析」「学習準備完了」で絞り込み、10件ずつ追加表示。通常の行は日時/順位/状態と主操作。対戦相手・保存日時・Windows受信状態は「詳細」へ。未同期は行にも表示。準備済みの「問題を見る」は紐付くレポートだけの問題一覧を開く。
- 設定: 学習の設定、保存と同期、端末の管理（記録保存/復旧・容量・ライセンス）。同期の異常や未送信は全タブ共通の上部に残し、詳細から保存と同期を開ける。学習画面にもオフライン保存未確認時だけ設定への入口を出す。

縦横とも復習/再開、自主練習、問題一覧の順に一列で配置する。問題の回答中は既存の画面内配置と下部タブ非表示を維持。「中断して学習へ」で戻る。タブ移動は履歴・登録・同期データを書き換えない。

Windows版のナビゲーション構成は別で、この変更では維持する。

検証: `npm test -- --config=playwright.phone-tabs.config.ts --project=phone` はPython coreと、日常サーバーへ接続しないEdgeの架空データ画面/ロジック検証を行う。生成画面の観測と実iPadのUX受入を区別する。
