# コンパクトな画面とSVG牌 — 11.02-3

本人が提示したiPhoneホーム/自主練習の画像と「縦にコンパクト」「必要以外のUI/文章を無くす」「実牌に近い軽量な牌素材」の依頼に対応する。

## 表示
- ホームのスローガンと重複した通常通信/未送信0の文言を省く。復習数と開始/再開・自主練習を小さいカードへまとめる。オフライン・未送信・同期中・エラーは引き続き表示。
- URL入力と保存を横並び。問題の端末保存/同期はホームに残し、取得日時・容量・保護状態・記録ファイルの保存/復旧は「端末の管理」にまとめる。
- 学習のモード・進捗・中断を一行にまとめ、重複するモード表示と余白を減らす。小画面では7枚ずつの2段と44px以上の選択領域を使い、選択後も別の「回答する」操作を必要とする。
- 答え合わせ時は手牌を小さい1段にし、卓を少し縮めて3者比較/自己評価を上げる。重み差の意味は開閉式で保持。取消/回答選び直し/評価取消は維持。
- 点数・席・河・副露・リーチ・ドラ・本場・供託は省かない。「副露なし/リーチなし」の常時説明は省き、該当時だけ表示。短い画面や副露の多い局面は必要なスクロールを許し、情報を切り取らない。
- Windows側もコピー/重複footerを省き、見出しと復習/回答欄を圧縮。取り込みなどの通知は固定の重なる表示から通常の文書内表示へ移し、手順操作を塞がない。バージョンはsidebarまたは小画面のtopbar、iPhoneはheaderに表示する。

## 牌素材
[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)のRegular SVGを固定revisionから同梱する。34通常牌+3赤五。CC0表記とライセンス原文、固定revision、加工内容は[third_partyの記録](../third_party/riichi-mahjong-tiles/README.md)。一九・萬筒索・風/三元・赤五を個別図柄にし、外部CDN/フォントに依存しない。

編集用メタデータと未使用定義をSVGO 4.0.0で除き、37種合計304,689 bytes（元765,988 bytes）。Viteのハッシュ付き配信/既存shellキャッシュへ含め、SVGのContent-Typeを明示。読み上げ名は画像と独立して維持。小さい画像はdata URL、残りは同一Originのキャッシュ済みSVGで表示する。DB/パック/同期/学習期限とIDに変更はない。

## 検証境界
生成データとEdgeの375×667/390×844/430×932およびdesktopで、手牌操作・回答・比較・自己評価・横溢れ・下部ナビとの位置を検査する。標準の390/430幅で、通常問題の回答と答え合わせ後の評価まで先頭画面に収まることを検査する。小さい375×667では読みやすさを守るため一部スクロールを許す。副露や長い河も非表示にしない。

全37図柄の識別、赤牌、読み上げ名、通信切断/再読込後の画像表示を検査する。既存P4/P5の保存・再起動・更新世代・受信確認・復旧も回帰検証に含む。自動検証は新たなSafari実機/本人の見た目の合格と区別する。既存の実iPhone合格を別の形式や今回の主観的UXへ広げない。
