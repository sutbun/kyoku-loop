## 本人が行う確認（解析を実行せずに止める）

今回は本人が導入済みと回答したBraveで確認する。Chromeへの追加導入は不要。提供元の記事はChrome/Edgeを案内しており、Braveでの実転送は別途本人確認とする。未導入なら先にその旨を伝え、転送操作へは進まない。公開配布ページの閲覧は導入・権限への同意を意味しない。

1. KyokuLoopの解析待ちから、本人の雀魂牌譜をそのブラウザで開く。必要なログインは本人が行う。
2. 「雀魂牌譜検討サポーター」でNAGAへ渡したい局を選び、転送する。確認対象はまず1局でよい。
3. 遷移先がNAGA公式であることと、選んだ局のデータが入ったことを確認する。ルール・タイプ・表示NPも確認する。
4. **ここで止める。解析依頼・NP購入は行わない。** 「転送できた」、または止まった画面の表示を返す。アカウント・残高・個人URL・牌譜内容の報告は不要。

全局/一部局の送信は、選んだ局と公式側の入力が一致することを個別に確認する。旧記事には見かけの局数と消費NPが一致しない場合の説明があり、現行画面でも同じ挙動とは断定しない。件数や内容に不明点があれば実行せず止める。

この確認は転送の実操作を確認するためのもの。有料解析の生成成功や全形式の対応を証明しない。解析前後に元対局と一致しない局が見つかった場合も、補正値を作ったり一致済みとみなしたりしない。
