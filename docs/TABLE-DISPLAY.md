# 卓と捨て牌の配置

各席から見た河を共通の座標で作り、卓の中心を軸に回転する。

| 画面の席 | 回転 | 最初の6枚 | 次段が増える方向 |
| --- | --- | --- | --- |
| 自分（下） | 0度 | 左から右 | 下 |
| 下家（右） | -90度 | 下から上 | 右 |
| 対面（上） | 180度 | 右から左 | 上 |
| 上家（左） | 90度 | 上から下 | 左 |

各席の視点では1段目が1〜6枚目、2段目が7〜12枚目、3段目が13枚目以降。
段が変わると左端へ戻り、蛇行しない。19枚目以降も3段目を右へ延ばし、4段目には折り返さない。
空の段を含めて開始位置は一定とし、牌の枚数で中央寄せし直さない。

正方形の中央情報を四方の河が囲む。席名と点数は河の外側の独立した情報欄に置き、河の開始位置を押し動かさない。
リーチ宣言牌はその席の通常方向から90度回し、横向きの幅をレイアウトに確保する。
副露された捨て牌は既存仕様どおり薄く表示し、時系列の位置を保持する。

デモ・Windowsの牌譜表示・学習・端末内復習で同じ河コンポーネントを使用する。
回答前の実打牌/推奨牌の非表示、手牌操作、保存形式、学習判定は変更しない。

## 画面検証

`tests/table-rivers.spec.ts` は架空データを使い、built assetsを隔離Edgeへ供給する。
専用の `npx playwright test --config=playwright.rivers.config.ts --workers=1` は1460のサーバーを起動/借用しない。
4方向の回転、6/7/12/13/18/19枚目、24枚時の3段構成、リーチ牌、牌同士/中央/席情報との重なり、卓外へのはみ出し、短い河の開始位置、回答前後の配置を検証する。
端末実機の読みやすさや主観的UX合格とは区別する。
